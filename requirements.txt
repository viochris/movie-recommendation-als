# NOTES (read before you `pip install` or run the notebook):
#
# 1. `pyspark` is a Python wrapper around the Java-based Apache Spark
#    engine. Installing the `pyspark` package with pip is NOT enough
#    on its own: you also need a working Java Development Kit (JDK)
#    installed on your system, with `JAVA_HOME` set and `java` on
#    your PATH. Java 17 (LTS) is the version most commonly recommended
#    for current Spark 3.x releases; Java 11 is also widely supported.
#    Run `java -version` in the same terminal you'll launch the
#    notebook from to confirm it resolves before running any Spark
#    code, or you'll hit a "JAVA_HOME is not set" style error.
#
# 2. The final trained model in this notebook is saved with Spark's
#    own model writer (`model.write().overwrite().save(path)`), which
#    produces a directory of Parquet and metadata files, not a single
#    `.joblib` or `.pkl` file. `joblib` is still listed here because
#    it's imported in the setup cell, but the ALS pipeline itself
#    does not use it for saving anything.
#
# 3. Several packages here (xgboost, lightgbm, catboost,
#    imbalanced-learn, lime, optuna) are imported in the notebook's
#    setup cell but are not actually used by the ALS pipeline itself.
#    They're included so the notebook runs top to bottom without an
#    ImportError, not because the recommender depends on them.
